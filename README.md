# Project Euler

My solutions to [Project Euler](https://projecteuler.net/) problems, written in Java.

This project is also an opportunity to practice Git, GitHub, and version control workflows.

## Goals

- Improve mathematical problem-solving and programming skills.
- Explore different algorithms and their efficiency.
- Gain practical experience with Git and GitHub.

## Solution Sharing Policy

In accordance with Project Euler's sharing guidelines, this repository contains solutions only to the first 100 problems. Solutions to later problems will not be published.
